# 🚀 NEXORA – Lost Today, Found Tomorrow

NEXORA is a **campus Lost & Found platform** that helps students report lost items, post found items, and connect with their rightful owners.

🌐 **Live Demo:** https://nexora-vvitu.netlify.app/login

## ✨ Features

- 🔐 User Login & Authentication
- 📢 Report Lost Items
- 📦 Report Found Items
- 🔎 Search & Find Items
- 🏫 Campus-focused platform
- 🎨 Modern & responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Netlify

## 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd NEXORA
npm install
npm run dev
```
